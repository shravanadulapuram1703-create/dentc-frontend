How to use

Each file is a standalone .svg. Drop it in an <img>, inline it, or set it as a CSS background. To recolor in your app, inline the SVG and override the tokens on any ancestor: --enamel-mid, --enamel-hi, --enamel-lo, --root-hi, --root-mid, --root-lo. The canonical orientation is crown-up; for the upper arch apply transform: scaleY(-1) (as shown above). Status states (selected, missing, treatment-planned) map cleanly to token overrides — e.g. tint enamel blue for a selected tooth, or swap roots to grey for "missing".
